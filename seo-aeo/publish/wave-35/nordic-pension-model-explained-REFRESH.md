# Nordic pensions: ATP is DKK 694 billion, GPFG is kroner — not DKK 435bn / $1.4T

Denmark, Sweden, Norway, and Finland run large mandatory and occupational books. That architecture is real. The live dollar table is not. The live page still assigns [ATP](/atp-denmark-pension-fund/) **approximately 435 billion Danish kroner as of late 2023**, [GPFG](/norges-bank-investment-management-nbim/) **over 1.4 trillion USD** and a leftover **70 / 25 / 5** sleeve, PensionDanmark **approximately 130 billion Danish kroner**, and Sweden’s AP funds **over 400 billion Swedish kronor**. Those leftovers are not the current filings.

Last updated: 26 August 2026.

## What the page can say

- **Two jobs.** An occupational book (ATP) is not a petroleum SWF (GPFG). Name the job before the number.
- **How to print the rest.** Name PensionDanmark or an AP fund. Say the current official line was not fetched this wake.
- **What a Nordic pile is not.** Adding leftover kroner, kronor, and homemade dollars into a regional stack is not a filing.
