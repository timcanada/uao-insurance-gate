# SWF private-markets allocation: no official $1.7T / $1.1T rank table

There is no official league table of sovereign wealth funds ranked by private-markets AUM. The live page still assigns Norway’s Government Pension Fund Global **$1.7 trillion** (and **75%** public equities as if that were a PE rank), SAFE **approximately $940 billion**, PIF **exceeding $925 billion**, CPP Investments **$630 billion**, and GIC plus Temasek **approximately $1.1 trillion**. Those dollars are not a private-markets filing.

Last updated: 26 August 2026.

| Temasek Holdings | **S$518 billion (US$401 billion)** at **31 March 2026** | GIC+Temasek **$1.1 trillion** |
| CPP Investments | **C$793.3 billion** at **31 March 2026**. CPP is a **pension**, not a SWF | **$630 billion**; **$200+ billion** PE as a UAO print |
| Combined “largest SWFs by private markets” | No official combined PE AUM | Any homemade rank that needs SAFE, GIC, or GPFG dollars |

Print kroner for GPFG. NBIM’s own half-year cut is listed-heavy: **72.1%** equities, **25.8%** fixed income, **1.6%** unlisted real estate, **0.5%** unlisted infrastructure. That is the opposite of a private-markets league-table win. Do not convert 22,683 billion kroner into **$1.7 trillion** so Norway can top a PE list it does not publish.

CPP is **not** a sovereign wealth fund. If it appears on this URL at all, print Canadian dollars and say so. Do not file it as a SWF PE champion at **$630 billion**.

Twin `/largest-swf-private-markets-allocation/` still returns 200 — 301 that URL here **after** this overwrite, not before.

## What this page can say

Some houses run large unlisted books. Some do not. Quote the filing, or say the house does not publish AUM or a PE sleeve. A rank table that needs SAFE **$940 billion** and GIC+Temasek **$1.1 trillion** is consultancy arithmetic.

## What is not official

- GPFG **$1.7 trillion**, or a PE-rank built on a homemade dollar.
- SAFE **$940 billion**.
- PIF **$925 billion** as current AUM.
- GIC+Temasek **$1.1 trillion**.
- CPP **$630 billion**, or CPP as a SWF.
