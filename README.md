# Universal Asset Owners

Public-facing assets for [Universal Asset Owners](https://www.universalassetowners.com) — research flipbooks plus the native mobile app.

- `mobile/` — Expo (iOS / Android / web) app that loads the live site library
- `lloyds-flipbook.html` / `pptx-flipbook.html` — interactive research readers
- `assets/` — flipbook page images
